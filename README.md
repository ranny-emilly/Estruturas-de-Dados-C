# 📚 Estruturas de Dados em C

Este repositório faz parte do meu **processo de aprendizado e aprofundamento em Estruturas de Dados utilizando a linguagem C**.

Ele foi criado durante um curso que estou realizando com foco em **entender de fato como as estruturas funcionam internamente**, especialmente no que diz respeito a **memória, ponteiros, alocação dinâmica e análise de custo computacional**.

O objetivo aqui **não é apenas implementar**, mas **compreender o porquê**.

---

## 🎯 Objetivos do repositório

* Consolidar os conceitos de **Algoritmos e Estruturas de Dados (AED)**
* Praticar estruturas clássicas em **C**
* Entender o funcionamento interno das estruturas (ponteiros, ligações, memória)
* Analisar **complexidade de tempo** e comportamento dos algoritmos
* Criar um material de **consulta pessoal** para revisões futuras

---

## 🧠 Conteúdos abordados

Ao longo do repositório, são estudadas e implementadas estruturas como:

* Vetores e manipulação básica
* Alocação estática e dinâmica (`malloc`, `free`)
* Ponteiros e passagem de parâmetros
* Listas encadeadas

  * Simples
  * Duplamente encadeadas
* Filas
* Operações de:

  * inserção
  * remoção
  * busca
  * atualização
* Análise de complexidade (ex.: O(n), O(log n))
* Busca linear e busca binária
* Manipulação de strings (`fgets`, etc.)

> ⚠️ A ênfase está no **entendimento conceitual**, não apenas no código final.

## 🛠️ Linguagem e abordagem

* Linguagem: **C**

  * foco em ponteiros
